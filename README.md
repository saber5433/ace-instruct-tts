# Anonymous Audio Supplement

## Paper

Self-Rewarding GRPO for Instruction-Guided Zero-Shot Speech Synthesis

Anonymous Authors

## How to listen

Open `index.html` in a modern browser.

The page uses relative audio paths and has no external dependencies.
If browser playback is unavailable, open the audio files directly
using the paths listed in `manifest.csv`.

## Files

- `index.html`: paper title, abstract, and listening interface
- `manifest.csv`: sample texts and audio paths
- `audio/`: included audio files
